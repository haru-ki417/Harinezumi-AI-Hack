# Vital Room — フロントエンド (Next.js)

同意付き・透明な双方向バイタル共有UI。ロビーで表示名・ルームコード・役割
（面接官/就活生）を入力し、同意後に機器設定・プレビューを確認して参加。カメラから自分の
心拍・HRV・ストレスを算出し、同じルームの相手と数値を互いに共有する
（相手の映像は共有しない）。

## 構成

```
frontend/
├── app/
│   ├── layout.tsx        # タイトル「バイタル共有ルーム」
│   ├── globals.css
│   ├── page.tsx          # 名前・同意→機器設定→ルーム(参加者カード)
│   └── page.module.css
├── hooks/
│   ├── useWebcam.ts      # カメラ→フレームBase64(25fps)
│   ├── useVitalRoom.ts   # /ws/room/{id} クライアント(同意送信・スナップショット受信)
│   ├── useVitalStream.ts # (単体モード用)WS/RESTクライアント・参考
│   └── useVitalAPI.ts    # (旧)REST版・参考
└── types/index.ts
```

## 起動

```bash
cd frontend
npm install
npm run dev        # http://localhost:3000
```

先にバックエンド(:8000)を起動しておくこと。

## 使い方(2人)

2人がそれぞれ `localhost:3000` を開き、**同じルームコード**を入力・役割を選び、
同意して機器設定に進み、プレビューを確認して「面接に接続」を押す。
互いのBPM・ストレス・HRVがカードで見える。自分の参加を終了する場合は「退出」、
全員の面接を終了する場合は面接官の「面接を終了」を押す。終了後はレポートが自動で開く。

### 参加前の設定

- カメラの選択、オン／オフ、左右反転、明るさ、背景ぼかし・背景色を確認できます。
- プレビュー下の「カメラ」「マイク」ボタンで、それぞれをワンクリックでオン／オフできます。
- マイクをオンにすると、選択したマイクの入力レベルを確認できます。
- スピーカーのテスト音を再生できます。出力先の切り替えに非対応のブラウザーでは端末の設定を使用します。
- 設定画面ではチャットには接続せず、画像・音声・バイタルも送信しません。「前の画面に戻る」で機器を停止します。
- カメラの設定は面接画面に引き継ぎます。カメラオフでも参加できますが、自分のバイタルは計測されません。
- マイクの選択・オン／オフは面接画面にも引き継ぎ、退出時に停止します。現状のアプリには相手への映像・音声配信機能はありません。

背景加工は [MediaPipe Image Segmenter](https://ai.google.dev/edge/mediapipe/solutions/vision/image_segmenter/web_js) を使って端末内で行います。
初回利用時に jsDelivr からバージョン固定の WASM、Google Storage から Selfie Segmenter のモデルを取得するため、インターネット接続が必要です。
読み込みに失敗した場合はエラーを表示し、再試行または背景「なし」で続けられます。
背景と明るさの加工は表示専用です。バイタルの計測には、従来どおり加工前の画像をバックエンドに送信します。

## バイタルのアラート

参加者ごとにストレスが70、またはBPMが100を**超える**と、カードとカメラの枠・下部の通知バーが赤くなります。
超えた項目の数値も強調し、ストレス超過時はストレスメーターも赤くします。設定値以下に戻ると解除します。
しきい値は `lib/vitalAlerts.ts` の `VITAL_ALERT_THRESHOLDS` で変更できます。初期値は表示確認用で、医学的な診断基準ではありません。
未計測・不正値は判定せず、カメラ停止中の自分の値と、ルーム切断中の値については通知を停止します。
既存の「変化あり」はバックエンドのベースライン変化判定として残ります。

## 面接終了後のレポート

面接官が「現在の話題」のボタンを押すか、自由入力欄に質問を入力して Enter を押すと、
新しい質問区間が Q1、Q2…の順に始まります。同じ話題をもう一度送信した場合も次の質問になります。
質問は1面接200件までです。上限に達しても、それまでの質問・計測履歴は維持します。
面接官の「面接を終了」で全員の計測・接続を停止し、それぞれの画面にレポートを自動表示します。
「退出」では退出した本人のレポートを開きます。「前回のレポート」から再表示できます。
面接中の「レポート」では、その時点までの集計を確認できます。

グラフは横軸が質問（Q1、Q2…）、縦軸がストレス指標または心拍数（BPM）です。
質問ごとの平均・最大値、基準線、基準超過した質問を表示し、表では最初に基準を超えた時刻と最大値の時刻を確認できます。
時刻は面接開始からの経過時間です。基準値はストレス指標 **70 超**、心拍数 **100 BPM 超**で、
ライブ画面と同じ `lib/vitalAlerts.ts` の設定を使います。これらは表示確認用の値で、医学的な診断基準ではありません。
信頼度が 0.5 未満の計測、不正値、未計測値は集計から除外し、データのない質問は欠測として残します。
顔が検出できない場合などに表示用に保持された古い値も除外します。入室・質問・計測の時刻はサーバー時刻を基準に合わせます。
ライブ画面のグラフが古い値を表示対象から外しても、レポート用の計測履歴は面接全体についてブラウザー内に保持します。
ページの再読み込みや新しい面接の開始で、前回のレポートは失われます。

終了後は質問ごとの集計結果を `/api/reports/analyze` に送り、コメントを自動作成します。
外部 AI を使う場合は、バックエンドを起動する環境に `OPENAI_API_KEY` を設定してください。
モデルは `OPENAI_REPORT_MODEL` で変更でき、既定値は `gpt-4o-mini` です。API キーはフロントエンドに設定しません。
外部 AI には匿名化した参加者識別子と集計値を渡し、表示名、質問の本文、画像、チャットは送りません。
AI のコメントは数値の変化と基準超過を説明するもので、感情や適性、採用可否を判定するものではありません。
API キー未設定、AI 接続失敗、データ不足の場合もグラフを表示し、AI によるコメントと区別した集計コメント・理由を表示します。
AI 分析は参加者20人までです。21人以上でも全員のグラフ・数値集計を表示します。

## チャット

「面接に接続」を押し、ルームへの入室が完了すると画面上部の「チャット」から同じルームの参加者と会話できます。
名前・同意の入力画面、機器設定画面、入室処理中にはチャットを表示せず、チャットサーバーにも接続しません。退出時や面接ルームの接続が切れたときはチャットも切断します。
画面の切り替えでも接続・履歴・下書きが引き継がれ、閉じている間の受信は未読件数で表示します。
Enter で送信、Shift+Enter で改行します。日本語入力の変換確定では送信しません。
1件2000文字までで、送信完了の応答を受けてから入力欄を空にします。切断や送信エラー時は下書きを保持し、「再接続」で接続し直せます。
「ファイルを添付」から PDF・写真などのファイルを選択できます。画像のコピー＆貼り付けや、入力欄へのファイルのドラッグ＆ドロップにも対応しています。
1回の送信につき5件まで、1ファイル10 MiBまで添付でき、本文なしでも送信できます。送信前は添付一覧から取り消せます。送信に失敗した場合は本文と添付を保持して再試行できます。
JPEG・PNG・GIF・WebPはチャット内に表示し、PDFなどのファイルはファイル名からダウンロードできます。同じルームの参加者だけが取得でき、途中参加者も履歴に残っている添付を取得できます。
直近100件をサーバーのメモリに保持し、途中参加者へ渡します。全員退出またはサーバー再起動で履歴は削除されます。
添付は一時保存され、履歴から外れた場合・全員退出・サーバー再起動時に取得できなくなるため、必要なファイルは退出前にダウンロードしてください。
チャット用の接続先は既定で `ws://localhost:8000/ws/chat/{room_id}` です。
別ホストで実行する場合は `NEXT_PUBLIC_WS_BASE_URL` に `ws://ホスト:ポート`（HTTPSでは `wss://...`）を指定します。

## 開発コマンド

- `npm run typecheck` : 型チェック
- `npm run lint`      : ESLint
- `npm run test:e2e`  : 機器設定・アラートのブラウザーテスト（バックエンド不要、仮想カメラ・マイクを使用）
- `npm run test:chat` : 実バックエンドと複数画面を使ったチャットのブラウザーテスト
- `npm run test:report` : 面接終了・質問別集計・欠測・AI応答・実バックエンド連携のテスト（外部AIは呼び出しません）

Playwright の Chromium が必要です（`npx playwright install chromium`）。
`test:chat` と `test:report` はバックエンドの依存をインストールした `.venv` を使用し、ポート8100と3100にテスト専用サーバーを起動します。
Pythonの場所を変える場合は `BACKEND_PYTHON` を設定してください。普段の8000番・3000番のサーバーは使用しません。

インストール済みの Edge を使う場合、
PowerShell で `$env:PLAYWRIGHT_CHANNEL='msedge'` を設定してからテストを実行できます。
テスト用サーバーはポート3100、ビルド出力は `.next-test` を使用します。
背景加工の実モデルを使う追加テストは `$env:TEST_BACKGROUND='1'` を設定して実行できます（外部通信あり）。

## メモ

送信間隔 `intervalMs: 40`(25fps)。医療用途ではない。
バイタルは数値として共有し、チャットでは入力した文章・表示名・添付ファイルを共有する。相手の映像は送られない。
