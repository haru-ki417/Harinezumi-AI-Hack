# Harinezumi-AI-Hack

チーム「Life & Medical Hackers」で開発した **VITAL ROOM** のリポジトリです。

- **VITAL ROOM（フル版）** — [vital-room/](vital-room/)
  非接触バイタル（rPPG）を同意のうえで共有しながら、対人面接・AI 面接ができる面接ワークスペース。Next.js（`frontend/`）と FastAPI（`backend/`）で動きます。
- **VITAL ROOM Web 版** — [vital-room/web/](vital-room/web/) ・ https://haru-ki417.github.io/Harinezumi-AI-Hack/
  フル版の計測と面接練習を、サーバーなしでブラウザーだけで動くように移植した追加の版。インストール不要でスマホからも試せます。
